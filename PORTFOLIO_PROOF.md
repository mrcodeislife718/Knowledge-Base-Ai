# Knowledge Base AI — Portfolio Proof Contract

**Track:** AI knowledge product

Completion requires accurate retrieval/answering, provenance, secure data handling, reliable deployment, and evidence that the system improves real knowledge workflows.

Required proof: representative ingestion/retrieval/answer scenarios; tests for indexing, retrieval, citations/provenance, stale/update behavior, permissions, and deletion; adversarial tests for prompt injection, poisoned documents, conflicting sources, missing context, and tenant leakage; benchmarks for retrieval quality, answer support, latency, cost, and update freshness; security/privacy; repeatable deployment; real-user usage and retention/value where commercialized.

**Next proof target:** build a labeled evaluation set with known source answers plus adversarial/contradictory documents and measure retrieval recall, grounded-answer precision, unsupported-claim rate, latency, and cost.
